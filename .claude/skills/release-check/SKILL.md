# Release check

Mode: `$ARGUMENTS` (`--quick` skips pytest + audio QA — fine for docs/crates/site-only changes)

## 1. Run the pipeline
```bash
bash .claude/skills/release-check/scripts/release_check.sh $ARGUMENTS
```
Steps (each PASS / FAIL / SKIP, logs in a temp dir printed at the end; exit code = number of failures):
1. `python -m pytest engine/tests -q`
2. `python tools/verify_audio.py music/tracks` (+ `music/practice`, `music/transitions` when rendered)
3. `validate_crate.py crates/*.csv` (SCHEMA §5)
4. `python tools/build_catalog.py` → `python tools/build_rekordbox_xml.py` → `python tools/build_site.py`
5. Rekordbox XML parses and has tracks
6. repo hygiene: audio only under `music/`, no WAV/AIFF/FLAC, covers ≤ 200 KB
7. serves the repo root with `python -m http.server` and runs
   `node .claude/skills/release-check/scripts/site_smoke.cjs http://127.0.0.1:<port>/docs/ --screens <dir>`
   (Playwright Chromium; desktop 1280 px + mobile 375 px; crawls up to 15 linked pages)

The smoke test can also run on its own against any URL, e.g. the deployed GitHub Pages site:
`node .claude/skills/release-check/scripts/site_smoke.cjs https://<user>.github.io/<repo>/`.
If Playwright is missing: `npm i -g playwright && npx playwright install chromium` (exit code 2 = couldn't run).

## 2. Beyond the script (do these by reading, they can't be automated well)
- Spot-check 2 random tracks: sidecar cues land on the right bars, `description_he`/`mix_tips_he` make sense.
- Independent BPM/key re-measure on a sample:
  `python tools/analyze_library.py music/tracks/<slug> --out /tmp/qa.csv --force --quiet`
  (Camelot may legitimately come out as the relative A↔B).
- Hebrew proofreading of changed `guide/`, `crates/*.md`, `sets/` and site copy.
- `git status`: nothing generated by mistake (render caches, WAVs, `__pycache__`, screenshots).

## 3. Report
A PASS/FAIL table, then each failure with the evidence (log tail), the file, and the owning agent
(music-producer / crate-digger / guide-writer / set-planner / web-designer). For the user: one Hebrew line —
"✅ הכל עובד" or what's broken and who fixes it. Never claim success for a step that was skipped.
