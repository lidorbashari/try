# DJ Lab website (`docs/`)

Static Hebrew (RTL) site generated by `tools/build_site.py`. No framework, no bundler: HTML + CSS + classic
vanilla JS (works over `http://` and mostly over `file://`).

## Build & preview

```bash
python tools/build_site.py          # regenerate pages + docs/data/*.js (waveform peaks cached in .render_cache/)
python -m http.server 8000          # run from the REPO ROOT, not from docs/
# open http://localhost:8000/docs/
```

Serve from the repo root: pages load audio/covers from `../music/...` using `<meta name="djlab-root">`.
The Mix Trainer and ZIP downloads need `http://` (browsers block `fetch` on `file://`).

## Layout

| path | what |
|---|---|
| `index.html`, `library.html`, `practice.html`, `about.html` | top-level pages |
| `guide/*.html` | course chapters (from `guide/*.md`) + index |
| `crates/*.html`, `sets/*.html` | crates (from `crates/*.md|csv`) and example sets |
| `tools/*.html` | Mix Trainer, Camelot wheel, BPM tools, Set Builder, Rekordbox XML generator |
| `data/*.js` | generated globals: `DJLAB_CATALOG`, `DJLAB_PEAKS`, `DJLAB_GUIDE`, `DJLAB_CRATES`, `DJLAB_SETS` |
| `assets/css/` | `site.css` (design system, all pages) + `tools.css` (tool pages) |
| `assets/js/` | `core.js` (helpers, Camelot, waveform), `player.js` (player bar, cards, drawer), one script per page; `icons.gen.js` is generated |

Everything under `docs/` except `assets/css`, `assets/js/*.js` (minus `icons.gen.js`), `assets/img` and this
file is generated — edit the sources or `tools/build_site.py`, then rebuild.

## Deploy

`.github/workflows/pages.yml` builds with `--no-peaks-if-missing` (reuses the committed `data/peaks.js`) and
publishes `docs/`, `music/`, `crates/` plus a root `index.html` that redirects to `docs/`.
